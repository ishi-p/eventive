Objective:
The Smart Event Management System exists to handle all college event activities through its automated event management system. The system stores all event information which includes details about the event and its organizers and participants and its venue and its budget requirements. The system achieves three benefits through its secure database which eliminates the need for manual tasks while it boosts operational productivity and maintains precise documentation.
Scope:
This project helps in tracking and managing college events including academic, cultural, technical, and sports events. The system provides an effortless process for registering both events and their participants while it enables attendance tracking and report creation. The system supports identification of events which receive highest attendance together with assessment of budget effectiveness.
Project Abstract:
The Event Management System is designed for managing events conducted in a college. The system has two users: Administrator and Event Coordinator. The Event Coordinator is responsible for entering event details such as event name, date, venue, department, and participant information. The system records both student registration information and their attendance data.
The Administrator has the authority to add, update, or delete event details and to provide login credentials to Event Coordinators. The administrator can thus track event expenses while supervising resource distribution and producing reports which include event schedules and participant lists and budget documents. The system provides a user-friendly interface which allows efficient management of college events.

# 📌 SMART EVENT MANAGEMENT SYSTEM — FINAL NOTES

---

## 🎯 PROJECT OBJECTIVE

The Smart Event Management System is designed to manage college events efficiently by automating event creation, registration, attendance tracking, expense monitoring, feedback collection, and analytics.

It eliminates manual processes and provides a centralized database-driven system.

---

## 🧱 DATABASE DESIGN

The system is built using Oracle Database with relational design and normalization.

## ⚙️ TRIGGERS IMPLEMENTED

---

### 🔥 1. AUTO CREATE ANALYTICS

When a new event is inserted:

```sql
AFTER INSERT ON EVENT
```

→ Automatically inserts into EVENT_ANALYTICS

---

### 🔥 2. ATTENDANCE DEFAULT

Attendance status defaults to:

```sql
DEFAULT 'Absent'
```

---

### 🔥 3. ANALYTICS UPDATE BASED ON ATTENDANCE

Whenever attendance is updated:

→ AttendanceScore recalculated

---

### 🔥 4. ANALYTICS BASED ON EXPENSE

When expense is inserted:

→ BudgetEfficiency updated

---

### 🔥 5. SUCCESS SCORE CALCULATION

SuccessScore = combination of:

* AttendanceScore
* BudgetEfficiency

---

### 🔥 6. OPTIONAL (NOT USED BUT POSSIBLE)

* Prevent duplicate registration
* Auto assign volunteers based on skill
* Auto recommend events
